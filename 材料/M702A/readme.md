# M702A 空气质量传感器（四方光电 Cubic）

## 简介

- 厂商：四方光电（Cubic Sensor and Instrument）
- 类型：激光 PM2.5 / 空气质量传感器模块（含 eCO2、CH2O、TVOC、PM2.5、PM10、温度、湿度）
- 通信：UART 串口，**主动上报模式**（传感器自行周期性发帧，主机被动接收）

## 接线（本项目 RP2040）

| M702A | RP2040 (Pico) |
|-------|---------------|
| TX    | GPIO1（UART0 RX，第 2 引脚） |
| VCC   | VBUS（5V） |
| GND   | GND |

> 主动上报模式只用到 UART 的 RX 方向（M702A 发、RP2040 收）。

## UART 参数

- 波特率：**9600**（如收不到数据，尝试 115200，以 datasheet 为准）
- 数据位 / 校验 / 停止位：8 / N / 1

## 主动上报帧格式（共 19 字节）

| 偏移 | 字节 | 内容 | 说明 |
|------|------|------|------|
| 0 | B1 | 0x3C | 帧头 1 |
| 1 | B2 | 0x02 | 帧头 2 |
| 2 | — | eCO2 高字节 | |
| 3 | — | eCO2 低字节 | |
| 4 | — | CH2O 高字节 | 甲醛 |
| 5 | — | CH2O 低字节 | |
| 6 | — | TVOC 高字节 | |
| 7 | — | TVOC 低字节 | |
| 8 | — | PM2.5 高字节 | |
| 9 | — | PM2.5 低字节 | |
| 10 | — | PM10 高字节 | |
| 11 | — | PM10 低字节 | |
| 12 | — | 温度整数 | bit7=1 为负 / 0 为正，低 7 位为绝对值。例：`0x9B` = -27 |
| 13 | — | 温度小数 | 小数部分 |
| 14 | — | 湿度整数 | |
| 15 | — | 湿度小数 | 小数部分 |
| 16 | — | 校验和 | 前 16 字节累加取低 8 位（**假设**，以 datasheet 为准） |

## 解析约定（代码按此实现，如与实际不符请改）

- 高/低字节均为**大端**（高字节在前）
- 温度 = 符号 ×（整数绝对值 + 小数 / 10），如 `0x9B` 且小数 `5` → -27.5 ℃
- 湿度 = 整数 + 小数 / 10（若 datasheet 为 2 位小数，把分母改成 100）
- 单位参考：eCO2 = ppm，CH2O = mg/m³，TVOC = mg/m³，PM2.5/PM10 = μg/m³，温度 = ℃，湿度 = %RH
  （最终以 datasheet 为准）
